# Com109-group8

## Project Theme
The project is a property-listing website built as a static front-end experience for a real estate company called Fernhill. The site focuses on showcasing homes, telling the company story, and providing a quick contact path for prospective buyers.

## Pages/Components and Assigned Group Member
- `pages/index.html` - landing page with hero section and brand messaging - Clare Quinn
- `pages/properties.html` - property listing page with filtering and search interactions - Carter Todd
- `pages/AboutUs.html` - company background and values - Ryan Magee
- `pages/ContactPage.html` - contact form with office details and submission feedback - Brayan Sudario
- Navigation Bar - Ryan Magee
