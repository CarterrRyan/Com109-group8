# Com109-group8

Fernhill is a property-listing website with multiple static pages and JavaScript-driven interactions.

## Pages
- `pages/index.html` — landing page
- `pages/properties.html` — browse and filter listings
- `pages/AboutUs.html` — company background
- `pages/ContactPage.html` — contact form and office details

## Tech
- HTML/CSS
- JavaScript (with jQuery)
